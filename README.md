# 组内工作常用 Skills

用于组内日常研究材料准备，基于个人使用习惯和实际工作经验整理，后续会结合使用反馈持续更新和完善。

## Skills

| Skill | 用途 |
|---|---|
| [科研项目申报书写作](grant-proposal-writing/SKILL.md) | 起草和修改申报内容、分配成果指标、编写预算说明。 |
| [研究方案PPT制作](research-proposal-ppt/SKILL.md) | 依据背景材料组织研究方案页面，统一文字、图文上下排列和研究主体。 |

两个 Skill 分别放在仓库根目录下的同名文件夹中，可独立安装和使用。使用时以当前任务要求、项目指南和指定模板为准。

## 安装与使用

将需要的完整 Skill 文件夹复制到 `~/.codex/skills/`，保留其中的 `SKILL.md`、`agents/` 及参考文件。

- 使用 `$grant-proposal-writing` 起草或修改申报材料。
- 使用 `$research-proposal-ppt` 组织或制作研究方案PPT。

实际制作或修改演示文件时，PPT Skill 配合环境中的 presentations Skill 使用。
