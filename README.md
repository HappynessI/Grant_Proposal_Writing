# Grant Proposal Writing

个人使用的中文科研项目申报书写作 Skill，用于辅助起草和修改申报内容、分配成果指标及编写预算说明。

内容基于个人写作习惯和实际使用经验整理，不是通用申报规范。后续会结合使用反馈持续更新和完善。

## 文件说明

- [SKILL.md](SKILL.md)：主要工作流程与写作要求。
- [预算说明](references/budget-writing.md)：预算编写方法及个人偏好。
- [指标分配](references/indicator-allocation.md)：成果指标分配与计数口径。

使用时以具体项目的指南、模板和要求为准。
