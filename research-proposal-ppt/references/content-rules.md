# 内容组织规则

## 默认报告结构

横向项目报告一般回答三个问题：行业为什么需要这项技术，我方具备什么能力，双方可以围绕哪些场景合作。没有其他要求时按下面的结构起草，具体章节和页数以规划方案为准。

| 部分 | 内容 | 素材来源 |
|---|---|---|
| 战略与行业机遇 | 技术发展、国家政策、行业需求、融合机会 | 政策文件、已有报告 |
| 单位介绍 | 历程、平台、团队、研究方向、成效、产教合作 | 单位介绍PPT |
| 科研方向与代表性成果 | 按领域和技术方向展开，这部分通常页数最多 | 各团队PPT、论文 |
| 建设方案或项目方案 | 动机、研究基础、研究方向、人员、实施计划 | 方案PPT |
| 总结与合作展望 | 技术体系、合作方向、结束页 | 按对象新写 |

政策背景可能同时出现在单位介绍和行业机遇两份素材里，放在行业机遇部分，不要重复。

## 把素材按领域合并

用户说“按领域做”时，按以下步骤处理：

1. 把每位老师的素材拆成背景、数据、方法、平台、验证、应用几类。
2. 把相近内容归入同一领域，再按技术主题划分方向。例如一个领域可以分为数据与基准、基础模型、精细感知、时序认知、行业应用。
3. 领域只保留一页背景，从各份素材里提炼共同的挑战。
4. 相同主题合并到同一页，例如几位老师的数据集放进“数据集与基准”。
5. 重复的材料合并，每个方向只保留最能说明问题的成果。
6. 页面不提“某老师做了什么”，关键句不用“团队”作主语，改用“学院”或直接写技术内容。合作单位的成果在图下用小字标注来源。

只有一位老师的领域，已有的“背景—技术—应用”结构可以保留，改标题和主语即可。

## 应用页

一个方向只要能和对方行业建立联系，就在该方向最后加一页应用，可以写已经开展的，也可以写希望开展的。

- 整个方向都属于应用时，放在领域最后。
- 写行业和场景，不写具体客户或地方公司的名称，除非用户要求。
- 素材没有行业应用时，可以根据方法推断设想，但要告诉用户这部分是推断，请其确认。
- 不同方向的应用场景不要重复。

## 页数

用户给定页数时严格执行。没有给定时参考：

| 单元 | 页数 |
|---|---|
| 单位介绍 | 8～10 页，概况部分压缩到 3 页左右 |
| 单个技术方向 | 3～4 页：背景、1～2 页工作、应用 |
| 内容较多的方向 | 再加 1 页细分方向，不超过 5 页 |
| 总结与合作展望 | 3 页 |

用户负责多个方向时，先估算总页数再动笔。内容太多时合并成多图页，把每项工作压缩成一个结果图和一个指标。

“强调效果”和“介绍技术”是两种不同要求，以老师最新要求为准。强调效果时多放指标、合作单位、获奖和产业化；介绍技术时多放方法图、结构图和结果图。

## 标题和编号

- 标题格式为“编号 领域——方向”，一行放下，模板内不超过 23 个汉字宽度。
- 同一方向的多页可以用相同编号。
- 复制素材后，把原有编号改成新报告的编号。
- 别人负责的页面不动。编号因此重复时告诉用户，等整体顺序确定后再统一修改。

## 素材常见问题

- 模板残留的隐藏文字，如与本页无关的旧标题。
- 从其他页面复制后没改完的正文。
- 地名、单位名错误，例如把某县写到另一个市下面。
- 多页人数或指标不一致。
- 证书内容和页面说法不一致，证书写的是另一项成果。
- 图片上的机构标识、模型名称和当前主体不符。

发现后直接修正可确认的错误并说明；无法确认的列给用户。
